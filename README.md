# 宛名はがき（開発版）

Windows向けの年賀はがきアプリです。住所録・宛名印刷に加え、2027年・未（ひつじ）のオリジナルデザイン6種類から選び、文面を変更して画像保存・デザイン面の印刷ができます。
## バージョン
ver0.01 　はがきのデザインと編集を可能にし、プリンタ接続を可能にした。pre版が完成した状態<br>
ver0.02   EXEファイルのZipをReleasesに添付した

## 起動

exe版は `dist\宛名はがき\宛名はがき.exe` をダブルクリックします。Windows 10 / 11の64ビット版向けで、Node.jsの追加インストールや管理者権限は不要です。exeと同じフォルダーにあるDLL、resources、locales等も必要なため、移す場合は「宛名はがき」フォルダーごと移してください。住所録・デザインの保存先は従来と同じドキュメント内の「宛名はがき」です。従来の「起動.cmd」も使用できます。

このPCでは、1ファイルにまとめたポータブル版の起動プログラムをWindowsのApplication Controlポリシーがブロックしました。セキュリティ設定は変更せず、起動確認ができるフォルダー同梱のexe版で配布します。

Node.jsを使用し、このフォルダーで `npm install` 後に `起動.cmd` を開きます。Electronのデスクトップウィンドウで起動します。インストーラー作成は未実装です。

起動時には、青いコーヒーカップと暖色の湯気が動く専用画面を表示します。文字や読み込みバーは表示しません。カップが「ぽわん、ぽわん」と上下し、湯気と周囲の波紋がやさしく動いて、約2秒を目安に住所録画面へ切り替わります。右上の×で起動を中止できます。Windowsでアニメーションを減らす設定をしている場合は、静止表示に切り替わります。

起動できない場合は黒い画面のエラーと、このフォルダーの `startup.log` を確認してください。起動処理はNode専用の環境設定を取り除いてElectronを実行します。依存パッケージのインストール後も実行ファイルがない場合は `node node_modules/electron/install.js` を実行してください。

二重に起動した場合は、既存のウィンドウを前面に表示します。ログとキャッシュはアプリ本体に書き込まず、ユーザー用フォルダーに保存します。exe版の起動ログは `%APPDATA%\atena-postcard\logs\startup.log`、キャッシュは同じ `atena-postcard\cache` 配下です。GPUのディスクキャッシュは使用しません。

`index.html` をブラウザーで開いても基本機能を試せます。ブラウザー版はブラウザー内に保存するため、ドキュメント内のフォルダーへ自動保存するには「起動.cmd」からデスクトップ版を使用してください。ブラウザー版からデスクトップ版へデータを移す場合は「全データをバックアップ」「バックアップから復元」を使ってください。

## 住所録の保存先

Windowsのドキュメント内の `宛名はがき` フォルダーに、次のファイルを自動作成します。この環境では `C:\Users\user\Documents\宛名はがき` です。Windowsでドキュメントの場所を変更している場合は、その場所を使用します。

- `住所録.json`：現在の住所録、差出人、印刷位置の設定。個別登録・CSV追加・編集・削除・復元の確定時に更新します。
- `住所録.backup.json`：ひとつ前に保存した内容。必要な場合は「バックアップから復元」で選択できます。

画面上部の「フォルダーを開く」で保存先を確認できます。最初の起動で、以前のデスクトップ版の保存データを自動で移行します。元の保存データは残し、ファイルが既に存在する場合はファイルの内容を優先するため、毎回追加されることはありません。

保存は一時ファイルへの書き込み後に置き換えます。読み込みに失敗した場合は通常の保存を停止し、空の住所録で上書きしません。壊れたファイルに対してバックアップからの復元を確定した場合は、復元前のファイルを `住所録.recovery-日時-識別子.json` として同じフォルダーに残します。

## 使い方

1. 「1人ずつ追加」で宛先を入力するか、「CSVからまとめて追加」で住所録を読み込みます。どちらも同じ住所録に追加されます。CSVは人数と内容を確認してから確定します。
2. 印刷したい宛先にチェックを付けます。氏名をクリックすると宛名プレビュー、行の「編集」を押すと編集画面が開きます。「差出人を設定」で自分の情報を登録できます。
3. 表・裏のプレビューをクリックすると、拡大して文字と配置を編集できます。項目を選んで文字を入力し、縦書き／横書き、大きさ、枠の幅・高さを設定します。ドラッグで配置を変えられます。
4. 印刷ボタンを押し、プリンターを選びます。最初は「まず1枚だけ試し刷りする」で位置と給紙方向を確認してください。はがき100×148mm、縦、倍率100%、片面でプリンターへ送ります。

CSVの見出しは `氏名,敬称,連名,郵便番号,住所,建物名` です。「氏名」「住所」が必須です。UTF-8とShift_JISのCSVに対応し、読み込み画面で文字コードを選べます。「見本のCSVを保存」でサンプルを作成できます。取り込みは既存の住所録に追加します。同一人物も追加されるため重複に注意してください。

住所録はドキュメント内に自動保存します。別の場所にも保管したい場合は、「住所録の保存・復元」から「全データをバックアップ」を選んでください。アプリからネットワークへの住所送信は行いません。

## 現時点の制約

- 現在のデザイン収録年は2027年です。翌年以降の干支デザインを自動生成する機能は含みません。

- 筆ぐるめ独自形式の直接読み込みは未実装です。対象バージョンと、架空の情報を入れたサンプル住所録を確認してから対応します。拡張子の変更だけでは取り込めません。
- 縦書き住所の数字は一桁ずつ漢数字に置換します。保存データは変更しません。長い住所、英字、連名の多い宛先はプレビューで確認が必要です。文字量に応じた完全自動組版は未実装です。
- 郵便番号からの住所補完、住所の実在確認は行いません。
- プリンターの給紙・余白に応じた実機確認が必要です。市販はがきの郵便番号枠は印刷しません。
- Windows上のテスト用ウィンドウで登録・CSV取り込み・選択・一括印刷の呼び出しを確認しています。実機プリンターの印刷結果は未検証です。

## 検証

`npm test` でCSVの往復、入力エラー、郵便番号正規化、縦書き数値変換、旧データの移行、ファイルへの保存・再読み込み、バックアップ、破損・書き込み失敗時のデータ保護を検証します。`npm run test:ui` は独立したテスト用データ領域を使い、個別登録とCSVの統合、取り込みのキャンセル、編集、検索中の選択、一括印刷に加え、ドキュメント相当のフォルダーへの保存と画面再読み込みまで検証して自動終了します。実機への印刷は行いません。

`npm run test:startup` は、独立したテスト用データ領域で起動画面のアニメーション、メイン画面への切り替え、起動中と起動後の二重起動防止、起動のキャンセルを確認します。テスト画面は自動で終了します。

### exeのビルドと検証

`npm run build:win` はWindows x64用のexeと必要なファイルを `dist\宛名はがき` に作成します。このフォルダー全体を配布してください。`dist\SHA256.txt` はexeのハッシュ、`dist\はじめに.txt` は簡単な使い方です。ビルドは[electron-builder公式のWindowsターゲット](https://www.electron.build/v26/docs/win/)を使用します。再ビルド前の出力は `.runtime/previous-builds` に移し、既存の住所録には触れません。

`npm run test:exe` は配布用exeを実際に起動し、ASAR内のプログラムと素材から動くこと、住所録の登録・CSV取り込み・保存・再読み込み、表裏の配置編集、完成PNG、印刷の呼び出し、二重起動防止、終了を確認します。診断用デバッガーを使って、そのプロセス内だけドキュメントとユーザー用フォルダーを `.runtime/exe-check-*` に切り替えます。普段の住所録は変更せず、印刷もテスト用プリンターへの呼び出しに置き換えます。続いて通常の保存先でも起動し、住所録の読み取り・デザイン表示・編集画面・終了を確認し、住所録のハッシュが変わらないことを確認します。通常起動の確認だけを行う場合は `npm run test:exe:launch` です。診断コードは配布用exeに含めません。結果は `.runtime/exe-test-result.json` と `.runtime/exe-normal-result.json` に保存します。

## 年賀状デザイン（うら面）

画面上部の「年賀状デザイン」タブで、2027年元旦に送る未年の絵柄を選べます。「和風」「かわいい」「水彩」「シンプル」で絞り込み、一覧から選ぶと右側のプレビューが切り替わります。「あいさつ文・文字を編集する」で見出し、文面、文字サイズ、年・日付、差出人表示を変更できます。選択と文面は自動保存します。

デザインは `ドキュメント\宛名はがき\年賀状デザイン\2027年_未（ひつじ）` に保存します。

- `01_和紙と金彩_背景.png` など6枚：文字のない生成背景の原画像。
- `01_和紙と金彩_完成見本.png` など6枚：標準の文面を合成した1200×1776ピクセルの年賀状。
- `選択中のデザイン.json`：アプリで選んだ絵柄、文面、各項目の配置。全デザインに共通の配置と、デザインごとの配置を区別して保存します。
- `作成した年賀状`：アプリの「完成した年賀状を画像で保存」で書き出したPNG。既存ファイルを上書きせず、別名で保存します。
- `デザイン一覧.json`、`はじめに.txt`、`生成プロンプト.md`：図案の一覧、使い方、生成方法とプロンプトの記録。

初めてデザインタブを開く際に必要な素材を専用フォルダーへコピーします。既に存在する素材は上書きしません。宛名面とデザイン面はそれぞれ別に印刷します。デザイン面の印刷枚数は専用欄で指定してください。フチなし印刷に対応しないプリンターでは余白が出る場合があります。

### 拡大して位置を編集

右側のプレビューをタップするか「拡大して配置を編集」を押すと、拡大編集画面が開きます。見出し、年・日付、あいさつ文、差出人、背景全体を選び、ドラッグして位置を移動できます。差出人は表示を有効にしたときに選択できます。背景全体は大きさも調整できます。背景画像内の羊や花などを個別に動かす機能はありません。

「全体表示」や倍率スライダーで拡大率を変え、数値入力や矢印キーでも調整できます。矢印キーは0.5mm、Shift＋矢印キーは2mm移動します。ドラッグ中にShiftを押すと縦または横に固定します。0.5mm単位の調整をオフにするかAltを押すと、より細かい位置に動かせます。「戻す」「やり直す」、Ctrl+Z、Ctrl+Yにも対応します。

位置を変更したら、下部で適用先を選びます。

- **このデザインだけ**：選んだデザインにだけ変更を保存します。
- **全6種類のデザイン**：動かした項目の配置を全6種類でそろえます。その項目に以前設定した個別配置も共通の配置にそろいます。動かしていない項目の配置は保持します。

「適用」を押したときに保存し、「変更せず戻る」や×、Escapeで閉じた場合は変更を保存しません。適用した配置は、一覧のサムネイル・大きなプレビュー・完成PNG・デザイン面の印刷に反映されます。標準の完成見本PNGは原本として残します。以前の文面設定ファイルもそのまま読み込めます。

### 表・裏の文字編集と縦書き／横書き

拡大編集画面で文字をクリックすると、右側に文面、文字の向き、大きさ、枠の幅・高さが表示されます。文字をダブルクリックすると入力欄へ移動します。編集した文面も「戻す」「やり直す」の対象です。文字や画像を自由に移動でき、枠外の内容ははがきの端で切れるため、プレビューで収まりを確認してください。

宛名面では、氏名・敬称・連名・住所・建物名・郵便番号・差出人・「年賀」の文字を編集できます。「この宛先だけ」または「住所録の全員」を選ぶと、変更した項目の配置・文字の向き・大きさをその範囲に適用します。宛先の氏名・住所などの文面は編集中の1人だけに保存し、他の人の氏名・住所を上書きしません。編集中に変更した差出人もその宛先専用になります。全員に共通する差出人は、画面上部の「差出人を設定」で変更できます。個別の差出人を設定済みの宛先には、その宛先の設定を優先します。配置は住所録と一緒にドキュメント内へ保存します。

うら面では、見出し・日付・あいさつ文・差出人の文面と書式を変更できます。差出人は表示を有効にすると編集できます。書式と配置の適用先は「このデザインだけ／全6種類」から選べます。文面は選択中の年賀状プロジェクトに保存され、絵柄を切り替えても保持します。背景は画像全体の移動・拡大縮小に対応しています。

## プリンターに接続して印刷

1. Windowsにプリンターを追加して接続します。
2. 宛名面は住所録のチェックで対象を選び、うら面は印刷枚数を指定して「印刷」を押します。
3. アプリの印刷画面でプリンターを選びます。接続後は「接続したプリンターを再読み込み」で一覧を更新できます。一覧を開くだけでは印刷しません。
4. 必要なら「プリンターの詳細設定を開いて印刷」を有効にし、はがきの種類・給紙トレイ・ふちなし等を機種に合わせて設定します。
5. 「まず1枚だけ試し刷りする」で確認してから、全枚数を印刷します。送信完了はプリンターへのジョブ送信を意味します。紙への出力はプリンター側で確認してください。

プリンターが未接続の場合は印刷開始を無効にし、接続・再読み込みの案内を表示します。ドライバーが印刷を拒否した場合はエラーを表示して再試行できます。表と裏は別々に印刷し、自動両面印刷は使用しません。ブラウザー版はブラウザーの印刷ダイアログを使用します。

検証では仮想プリンターへの呼び出しと、印刷データの100×148mmのページサイズ・宛名3ページ／裏2ページを確認しました。実機プリンターは未定のため、実際の給紙・余白・印字位置は未検証です。印刷APIは[Electron公式ドキュメント](https://www.electronjs.org/docs/latest/api/web-contents#contentsprintoptions-callback)に基づいています。

筆ぐるめ公式の[「おすすめ！はがき素材」](https://fudegurume.jp/fgw/katsuyou/howto/searchlayout.html)を操作分類の参考にしました。画像は組み込みimage_genで新規作成し、筆ぐるめの素材・ロゴを含みません。原画像は `assets/designs/2027`、プロンプト一式は同フォルダーの `生成プロンプト.md` に保存しています。

見本画像を再作成する場合は `node scripts/run-render-samples.cjs`、専用フォルダーへ素材を配置する場合は `node scripts/install-designs.cjs --documents "C:\Users\user\Documents"` を実行できます。`npm run test:ui` は絵柄選択・絞り込み・文面変更・保存・再読み込み・PNG書き出しと、指定枚数での印刷準備も確認します。
